## 📦 Installing Dependencies Locally (Without Virtual Environment)

This project installs dependencies inside a local `libs/` folder.

### 1️⃣ Install Dependencies

Run the following command inside the project folder:

```
pip install -r requirements.txt --target ./libs
```

This will create a `libs/` folder containing all required libraries.

---

### 2️⃣ Run the Application

```
python attendence_server.py
```

---

### 🌐 Open in Browser

```
http://localhost:8080
```

---

⚠ Note:
Python must already be installed on your system.
